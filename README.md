# nezam-social-assets

Public image assets for Nezam AI social posts.

Buffer's API cannot accept an uploaded file: every image on a scheduled post
has to be a URL Buffer can fetch. This repo is that URL. Files are pushed here
by `buffer.py upload` in the `nezam-buffer` skill and referenced by their
`raw.githubusercontent.com` address.

Everything here is public the moment it is pushed, including a carousel that
has not posted yet. Nothing confidential, nothing client-identifying, and
nothing covered by the PMT firewall belongs in this repo.
